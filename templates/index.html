B.Tech AIML Mini Project • Experiment 12 Dataset: UCI PhiUSIIL (235,795 Records)

AI-Based Phishing Website Detection & Classification

An end-to-end Machine Learning solution designed to classify URLs, predict phishing probabilities, and generate explainable risk scores using multi-model ensemble evaluation.

1. What the Model Does

Performs Supervised Binary Classification. It detects whether an unknown URL is Phishing (Class 0) or Legitimate (Class 1) based on 54 structural & lexical features.

2. Unique Dataset Used

Trained on the official PhiUSIIL Phishing URL Dataset from the UCI Machine Learning Repository containing 235,795 verified URLs with 54 features.

3. Models Compared & Evaluated

Compared 5 ML Algorithms (Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, XGBoost) using Stratified 80-20 train-test splits and weighted F1-Score scoring.

Data Preprocessing

Cleaning missing values, eliminating raw text identifiers, categorical encoding, and StandardScaler normalization.

Model Development

Training 5 supervised learning models with Stratified 80-20 holdout split to prevent test set data leakage.

Phase 3
Evaluation & Selection

Comprehensive evaluation using Accuracy, Precision, Recall, F1, ROC-AUC, and Confusion Matrices.

Phase 4
Actual Result Output

Live demonstration predicting URL class label, risk score, and verifying successful task performance.
