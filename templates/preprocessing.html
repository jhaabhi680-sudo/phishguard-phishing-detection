Data Preprocessing Methodology
Step 1
Data Cleansing

Evaluated null values and removed duplicate URL entries. Verified zero corruption in target labels (0=Phishing, 1=Legitimate).

Step 2
Feature Pruning

Excluded arbitrary text identifiers (URL, Domain, Title, FILENAME) to ensure the models learn generalized lexical patterns.

Step 3
Categorical Encoding

Transformed boolean flags (e.g., IsHTTPS, HasObfuscation, Bank, Crypto) into binary numeric indicators (0/1).

Step 4
Stratified Train-Test Split (80/20)

Split into 188,636 training samples and 47,159 testing samples using stratify=y and random_state=42. Stratification ensures both sets maintain identical class proportions.

Step 5
StandardScaler (Zero Data Leakage)

Scaled continuous features to zero mean and unit variance. Crucially, fit() was executed only on training data, and then applied to test data to prevent information leakage.
