REST API Documentation & Console

Integrate real-time ML phishing classification into browser extensions, SIEM pipelines, and secure web gateways.

REST v2.4 Active
POST /api/analyze
JSON

Analyzes a single URL using static lexical heuristics and ensemble ML classification.

Request Body
{
  "url": "https://secure-account-verification-example.com/login"
}
Response (200 OK)
{
  "status": "success",
  "url": "https://secure-account-verification-example.com/login",
  "prediction": "PHISHING",
  "confidence": 88.5,
  "risk_score": 92.4,
  "risk_level": "HIGH",
  "contributing_factors": [
    "Suspicious keywords found: login, account, secure",
    "Multiple hyphens (3) in domain - brand mimicry",
    "Long domain name (39 chars)"
  ],
  "safety_recommendation": "HIGH RISK: Strong phishing indicators detected."
}
POST /api/analyze-batch
Up to 50 URLs

Evaluates a batch array of URLs concurrently and provides aggregate threat statistics.

Request Body
{
  "urls": [
    "https://google.com",
    "http://fake-banking-login.xyz/auth"
  ]
