Requirement 1
Real-World Problem & AI Solution

Problem: Phishing is one of the most destructive cyber threats, accounting for over 36% of credential and financial data breaches. Attackers construct fraudulent domains mimicking authentic institutions. Traditional IP/domain blacklists fail against zero-day phishing domains.

AI/ML Solution: An autonomous machine learning pipeline that extracts 54 structural, lexical, and cryptographic features from any URL string statically (without visiting or running malicious scripts) and delivers real-time classification.

Requirement 3
Data Preprocessing & Scaling
  • Null & Duplicate Filtering: Cleaned all records and verified label integrity.
  • Pruning: Removed raw text columns (URL, Domain, Title) to prevent overfitting.
  • Encoding: Transformed boolean and categorical indicators into numeric vectors.
  • Stratified 80/20 Split: 188,636 train records and 47,159 test records maintaining balanced class distribution.
  • StandardScaler Data Leakage Guard: Normalization fit strictly on training set only.
Requirement 4
Multiple Model Development & Comparison

Trained and benchmarked 5 distinct machine learning algorithms:

Logistic Regression Decision Tree Random Forest Gradient Boosting XGBoost Classifier
Evaluated on Accuracy, Precision, Recall, F1-Score, and ROC-AUC. Composite selection weighted F1 (40%) and Recall (20%) to penalize dangerous False Negatives.
Requirement 5 & 6 (Core Rubric)
What the Model Does & Actual Output Demonstration

What the Model Does: The model performs Supervised Binary Classification. Given an unseen URL string, it maps the extracted 54 lexical/structural features into a binary label: Class 0 (Phishing) or Class 1 (Legitimate), accompanied by an empirical risk score (0–100%) and probability estimate.

Quick Viva Voce Q&A Reference Guide
Q1: Why was StandardScaler fit only on the training set? To strictly prevent data leakage. If the scaler sees test set distributions, the test set becomes biased and is no longer an honest representation of unseen real-world data.
Q2: Why is F1-Score more critical than Accuracy in phishing detection? Phishing datasets can have imbalance. More importantly, missing a phishing site (False Negative) leads to user credential theft, which is far worse than a false alarm. F1 and Recall balance both error types.
Q3: What are the primary features indicating phishing in a URL? High Shannon entropy (randomness), excessive length, multiple subdomains, brand token clustering (e.g. 'paypal', 'secure', 'login'), and abnormal hyphen counts in the domain.
Q4: Why use static URL analysis instead of loading the page? Zero execution threat. Static analysis evaluates the URL text in under 5ms without triggering drive-by malware downloads, malicious iframes, or alerting attackers.
